## About this session

Moving from developer to architect takes more than more technical skill.
It takes a different way of thinking about problems, decisions, and solutions.

Melissa walked through the architect mindset and how it differs from a
developer mindset, then taught process mapping for solution design: the
practice she credits with getting her through the CTA exam.

## Try the exercise yourself

The practice scenario is in the Process Mapping deck. Green Roof Systems
designs and installs green roofs in large metropolitan areas. Read the
requirements, give yourself five minutes, and draw the process out by hand
before you look at anything else.

Then compare against Anh's version above. There is no single right answer,
which is part of the point.
