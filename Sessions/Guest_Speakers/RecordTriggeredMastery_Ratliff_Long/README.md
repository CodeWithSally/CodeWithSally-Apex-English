# Record Triggered Mastery: When to Flow and When to Code

Community session with **Scott Ratliff** (Principal Architect Evangelist, Salesforce)
and **Michelle Long** (Senior Solutions Architect, Salesforce), hosted by Code With Sally.

This session translates the Salesforce Record-Triggered Automation Decision Guide into a
practical roadmap for choosing between Flow and Apex: measuring automation density, applying
implementation best practices, and designing for high-volume scale.

## In this folder
- `Record_Triggered_Mastery_-_When_to_Flow_and_When_to_Code.pdf` — session slides

## Topics covered
- The mindshift: choosing Flow vs Apex by data model and landscape, not comfort zone
- Automation Density: quantity, volume, and dependency sprawl
- Density levels mapped to architecture (Record-Triggered Flow, Hybrid, Apex Metadata Framework)
- The "One Entry Point" rule and the Metadata-Driven Trigger Framework
- Performance: before-save updates, SOQL deduplication, recursion control, bulk bypasses
- Designing for scale: async Flows, Change Data Capture (CDC), scheduled jobs
- Governance: documentation, naming, and DevOps
- Live Agentforce Vibes 2.0 demos throughout
