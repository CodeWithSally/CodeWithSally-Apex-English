# Goodbye Developer Console: Master Web Console + Agentforce Vibes on Your Phone

Community session with **Hussien Negm** (Associate Solutions Engineer, Arcsen), hosted by Code With Sally.

📅 Saturday, November 21, 2026
🕛 12:00 PM to 1:30 PM ET
💻 Free on Zoom, join us live: https://us06web.zoom.us/j/81873742891?pwd=WAAt75Sb5OULeiCovO677O4Q8sM6Bg.1

Since Winter '27, Developer Console is switched off by default and Web Console is the browser-based IDE built into your Salesforce org. This session walks through the everyday tasks the Web Console way, then compares it with Agentforce Vibes IDE and builds a Lightning Web Component from a phone.

## What we'll cover

- Running anonymous Apex, reading debug logs and setting trace flags
- Creating and testing Apex classes
- Building queries with the SOQL Builder and browsing metadata with the Org Browser
- The gotchas that catch people out in their first week
- Agentforce Vibes IDE vs Web Console: what each can do, and when to use which
- Building and deploying a Lightning Web Component to the Home page from a phone
